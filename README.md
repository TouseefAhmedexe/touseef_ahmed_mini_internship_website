# Mini Internship Website

A small multi-section internship website built with HTML only (no CSS, no JavaScript).
Task 5 of my Bloomrix internship.

## Sections
- Home
- About
- Skills
- Training
- Assignments
- Contact

## Files
- index.html - the website
- images/ - banner images and favicon
- media/ - sample audio, video
- pages/html-cheat-sheet.html - page shown in the iframe

## How to run
Open index.html with Live Server in Visual Studio Code, or in any web browser.
