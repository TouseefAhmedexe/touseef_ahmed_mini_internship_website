Frequently Asked Questions

Why does the website have no colors or layout?

The assignment allows only HTML, so the page has no CSS.

Does the contact form send a message?

No. The form has no server code, so submitting it reloads the page.

Why does the Close button work on the welcome dialog?

A form with method="dialog" closes the dialog that contains it.

What do the bars in the Skills section show?

They are meter elements that show my own rating from 0 to 10.
